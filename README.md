# @vlasou/log

Lightweight JavaScript logging with ANSI terminal styling, configurable log levels and type-safe ESM exports.

This repository is a **PUBLIC mirror** of reviewed source from the private NEXIS project. It is not a deployed Production mirror.

Sanitized source snapshots will be delivered to `dev` using a dedicated GitHub App. Releases of `@vlasou/log` to GitHub Packages (`https://npm.pkg.github.com`) follow reviewed `dev → main` pull requests. No npmjs.com publication is planned.

> Repository initialization only. No private code, credentials, or private Git history have been transferred.
